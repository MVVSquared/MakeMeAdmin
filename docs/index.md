This site documents **this fork of Make Me Admin** (version 2.3.84). It is based on the original project from Sinclair Community College and adds Entra / Intune enrolment-based authorization, Intune packaging, and HTTPS web logging. [What is different from the original](this-fork.md).

You can download installers for the original 2.3 build from [the upstream GitHub repository](https://github.com/pseymour/MakeMeAdmin/tree/v2.3-fr/Installers "Make Me Admin 2.3 installers").

If you prefer Chocolatey, teknowledgist has created a [package](https://chocolatey.org/packages/makemeadmin/2.3 "Chocolatey package for Make Me Admin 2.3") for Make Me Admin 2.3.
