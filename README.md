# Make Me Admin
Make Me Admin is a simple application for Windows that allows standard user accounts to be elevated to administrator-level, on a temporary basis.

This repository is a **fork** of [pseymour/MakeMeAdmin](https://github.com/pseymour/MakeMeAdmin) (version **2.3.84**). It keeps the original temporary-admin model and adds Entra / Intune enrolled-user authorization, Intune MSI packaging, and HTTPS web logging. See [What's Different in This Version](docs/this-fork.md).

Upstream documentation is in the [original wiki](https://github.com/pseymour/MakeMeAdmin/wiki). Documentation for this fork is in [docs](docs/index.md).
